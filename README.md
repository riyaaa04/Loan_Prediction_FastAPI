# Loan Prediction System

A machine learning based loan approval prediction system built using FastAPI, Streamlit, MySQL, and Docker.

## Architecture

User
|
Streamlit Frontend
|
FastAPI Backend
|
Machine Learning Model
|
MySQL Database


## Tech Stack

- Python
- FastAPI
- Streamlit
- MySQL
- Docker
- Docker Compose
- Scikit-learn


## Features

- User enters applicant details
- ML model predicts loan approval
- Prediction is stored in MySQL
- Database runs inside Docker container
- Complete application runs using Docker Compose
